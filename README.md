# Белый город — сайт ресторана

Одностраничный сайт ресторана и банкетного зала «Белый город» (Москва, Петрозаводская ул., 1). Сделан на чистых HTML, CSS и JS, без сборки, поэтому работает на GitHub Pages как есть.

## Структура
- `index.html` — вся страница
- `assets/css/style.css` — стили: палитра «бежевый · светло-коричневый · синий», адаптив
- `assets/js/menu-data.js` — меню, ~90 позиций (из Яндекс Карт и Restoclub)
- `assets/js/main.js` — слайдер, меню, калькулятор банкета, галерея, форма брони
- `assets/img/` — фото из галереи ресторана на Яндекс Картах
- `PROMPTS.md` — промпты для генерации видео и недостающих фото

## Запуск локально
```bash
python3 -m http.server 8000
```
Затем откройте http://localhost:8000

## Источники данных
- Описание, кухня, вместимость до 170 гостей и отзывы — с restoclub.ru
- Меню с ценами, часы работы, телефон, соцсети, особенности, рейтинг 4,4 и отзывы — с Яндекс Карт
- Акции взяты с афиш ресторана: −20% по будням 12–16, до −30% именинникам, Апероль 1+1=3, коктейль за сторис, банкеты от 3000 ₽
